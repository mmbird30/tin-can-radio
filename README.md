# 隔空传声筒

网页对讲机。把对讲链接发给朋友，双方打开同一个页面，谁按住橙色通话键谁说话，松开就听对方。

## 开始玩

1. 把 `dist/index.html` 放到支持 HTTPS 的静态网站上（见下方「托管」），用 Edge、Chrome 或 Safari 打开。页面的 HTML、CSS 和交互代码都在这一个文件中，无需安装依赖。
2. 点橙色键「开启麦克风」，允许浏览器使用麦克风。再点「复制对讲链接」，发给朋友。复制按钮受限时，可手动复制页面显示的链接。
3. 朋友打开链接，同样点橙色键并允许使用麦克风，就进入了同一个频道。
4. 显示「对方已连接」后，按住橙色键或空格键说话，松开即静音。对方说话的声音会自动播放。双方在通话时都将页面留在前台。
5. 点「结束本轮」会释放麦克风并换一个新频道。再玩一次时重新复制对讲链接。

同一个链接也可以发给多个人，大家会进入同一个频道。

## 托管

朋友要能打开链接，页面必须放在 HTTPS 网站上，比如 GitHub Pages、Cloudflare Pages 或 Netlify。只需上传 `dist/index.html` 这一个文件。手机浏览器也只允许 HTTPS 页面使用麦克风。

## 本地预览

在项目目录中运行：

```powershell
py -m http.server 8787 --bind 127.0.0.1 --directory dist
```

在本机打开 <http://localhost:8787>。本地地址生成的对讲链接只能在这台电脑上打开，适合用两个标签页自己测试。

## 连接方式

页面使用 VDO.Ninja 浏览器 SDK 1.6.2 和 WebRTC。每轮随机生成房间名和口令，放在链接的 `#` 后面，所以不会发送给托管网站的服务器。拿到链接的人都可以加入。每个人进入房间后发布自己的音轨，并自动收听房间里其他人的音轨。

双方网络都需要能访问 VDO.Ninja。如果提示语音服务连接失败，展开「连接帮助」，打开「兼容对讲页」。兼容页用 VDO.Ninja 自己的界面进入同一频道，用它的麦克风按钮切换发言和静音，关掉该标签页即可结束。SDK 项目与接口说明见 [VDO.Ninja SDK](https://sdk.vdo.ninja/)。
